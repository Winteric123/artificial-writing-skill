# STK11 expanded reference directory

Imported 2026-09-19 from the authorized STK11 mutation/co-mutation search: **44 unique DOI records across 20 journals**. The [CSV](stk11-expanded-reference-directory.csv) retains titles, years, identifiers, source links, topic tags, relevance, cautions, and a dated local-status snapshot. This is a cross-journal discovery/reference index, **not a read corpus, language bank, complete systematic review, or bulk highlight list**.

## How to retrieve

1. Filter journal, year, mutation/co-mutation context, clinical/mechanistic question, and relevance.
2. Prefer exact DOI/PMID identity over title fragments. Blank PMID means unconfirmed, not absent from PubMed. The single abbreviated title remains explicitly flagged.
3. Treat P1/P2/P3 as search-priority labels, not the user's highlight designation.
4. Join the current journal bibliography, reading ledger and quality register before reporting acquisition, completion, or acceptance. Snapshot fields do not override later journal records.
5. Read full sources before extracting language or promoting reading status. Keep new journal assets separate. Exclude commentaries/editorials/replies; correction notices are version-control metadata, not language-learning articles.
6. Consult [STK11 highlights](stk11-priority-references.md) only for user-designated writing-framework priorities.
